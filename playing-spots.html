Playing Spots

Spots/Advertisements or short audio clips are something optional that can be implemented and needs to be configured by the club itself.

What is a spot

These are normally used as sponsoring clips and can contain a website url to be opened on click as well as a bannerUrl to display as image.

The complete MycrocastSpot looks the following:

/// A single spot, this is an advertisement configured from our platform
public struct MycrocastSpot: Equatable {
    /// The id of the spot
    public var id: Int

    /// How long is the duration of the spot
    public var duration: Int

    /// The url of the audio file to be played
    public var url: String

    /// An advertisement can have a banner configured
    /// This is the title of the banner
    public var title: String?

    /// This is the url to the image of the banner
    public var bannerUrl: String?

    /// The banner can have a call to action link like a webpage configured
    /// This is the specific url
    public var websiteUrl: String?
}

Access to spots

To get access to the spots you need to use MycrocastRaydioSDK/SpotAccess

/// Interface to handle anything related to spots (advertisements)
public protocol SpotAccess {
    /// Publisher that riggers when a new Spot should be played
    var spotPlay$: AnyPublisher<[MycrocastSpot], Never> {get}

    /// if you do not want to use the reactive way provided by the combine publisher,
    ///  use this delegate to receive spot plays
    var spotPlayDelegate: SpotPlayDelegate? { get set }


    /// Call this function after you have finished playing an advertisement with the id of the advertisement
    /// This is needed for tracking purposes
    func spotPlayed(spotId: Int)
}

After playing a spot you need to call SpotAccess/spotPlayed(_) to register the playback. This is required for statistical purposes.

You can evaluate if you want to actually play an advertisement based on some kind of metric.

When are spot plays triggered?

The first time is during connection, if the user did not have a spot play in the last 12.5 Minutes. Apart from the “PreSteam” “InStream” spots can be triggered from the streamer itself via the streaming plattform.
