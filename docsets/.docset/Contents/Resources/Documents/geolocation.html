Geolocation

Geolocation can be used to restrict the streams that are visible within the app.

The use case is either due to some licensing rights, the streams should only be available in the stadion or in general a limited availability.

This feature is optional and if no location is provided, all currently available streams are loaded for the account.

Locations are currently managed by mycrocast and can be configured on a club or streamer level.

How to pass a location

The location is to be expected to be passed on the initialisation of the SDK in the RaydioSDK/start(_,_)Function call.

The location looks the following:

/// The location of the user
public struct Location : Encodable {
    public var latitude: Double
    public var longitude: Double

    public init(latitude: Double, longitude: Double) {
        self.latitude = latitude
        self.longitude = longitude
    }
}
